TP2 : Introduction au développement de DApps (NFT)

Objectifs

  • Se familiariser avec les outils de développement d'applications décentralisées (smart contracts, Web3, Hardhat, Remix, MetaMask).
  • Développer une DApp personnalisée de gestion de NFTs.
  • La déployer sur son propre réseau blockchain (Besu).
  • Programmer et exécuter des scénarios de tests.

Questions

Question 1 : Hardhat

Hardhat permet de compiler, déployer, tester et déboguer des contrats, et de lancer un réseau blockchain local.

  1. Installez Node.js.
  2. Installez Hardhat : npm install --save-dev hardhat.
  3. Initialisez un projet Hardhat.
  4. Lancez un réseau local pour le développement de votre DApp.

Question 2 : Remix

  • Lancez la version web de Remix et consultez l'espace de travail par défaut.
  • Lisez le code des contrats fournis, compilez-les, déployez-les et testez-les.

Question 3 : DApp NFT de base

  • Lisez attentivement la documentation de Hardhat.
  • Sous Remix, créez ou ajoutez un contrat ERC-721 simple pour gérer des NFTs.
  • Développez une DApp NFT de base avec Hardhat, IPFS, Web3.js et MetaMask en vous appuyant sur le tutoriel NFT.
  • Écrivez des scénarios de tests Hardhat (au moins : création par le propriétaire, refus de création par un autre compte, transfert d'un NFT).

Question 4 : personnalisation

  • Modifiez l'interface pour afficher la galerie des NFTs créés (indices : tokenCounter, ownerOf, tokenURI).
  • Ajoutez la création, le transfert (safeTransferFrom) et la consultation des NFTs.

Question 5 : déploiement sur le réseau Besu

  • Relancez le réseau configuré dans le TP1.
  • Configurez MetaMask pour interagir avec votre réseau Besu local.
  • Déployez la DApp NFT sur votre réseau privé.
  • Testez le système : création, transfert, affichage.

Modalités de rendu

Déposez le code de la DApp avec un fichier README.md détaillant les étapes pour la lancer.
